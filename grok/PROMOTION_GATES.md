# Promotion gates

The bot earns scope. It does not start as lead engineer.

## Gate 1 — Reviewer

Reject: VST as Logic native, Lua as Scripter, JavaScript as MDS, malloc in AU render, command-sent as confirmed, AX paths as stable. Knowledge + code-review evals must pass.

## Gate 2 — Research engineer

Source-backed matrices, honest tags, minimal probes, no unsupported VERIFIED. Twenty consecutive research tasks without a fake VERIFIED.

## Gate 3 — Component builder

Isolated pieces only: envelope, host detect, CoreMIDI endpoints, MCU codec, AX explorer, probe runner. Each needs unit tests, failure cases, source notes.

## Gate 4 — Lead Logic engineer

Only after readback, fixtures, rollback, multi-channel routing, and honest envelopes exist. Then larger implementation tasks.

v0 is Gate 1 material plus a stub component. It has not passed Gate 4.
